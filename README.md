# JSON Compare (Chrome 扩展插件)

面向开发者的结构化 JSON 接口差异对比工具，专为在不同环境（开发、测试、预发、线上）或不同版本之间快速排查有意义的业务字段变动而设计。

---

## 🌟 核心特性

- **纯前端与完全本地化**：所有数据解析与对比计算均在浏览器本地内存中完成，无任何网络请求，断网可用，隐私安全。
- **独立大屏标签页**：点击扩展栏图标即可在新标签页打开全屏双栏对比界面，舒适处理超长接口返回值。
- **结构化智能对比**：
  - **键名顺序无关**：对象内部字段顺序不同不计入差异。
  - **精确区分类型与空值**：严格区分 `undefined` (不存在)、`null`、空字符串 `""`、`0` 与 `false`。
  - **高精度无损数值解析**：支持长整数 ID（避免 JavaScript `Number.MAX_SAFE_INTEGER` 精度截断造成误判），并将数值相同的不同合法写法（如 `1` 与 `1.0`，`100` 与 `1e2`）判定为相等。
  - **层级差异收敛**：对象或数组整体新增、删除、类型改变时，收敛为单条父级差异，避免冗余重复报警。
- **路径级噪声过滤 (JSON Pointer)**：
  - 支持 RFC 6901 规范的 JSON Pointer（支持带点号、斜杠等特殊字符的字段名）。
  - 支持一键忽略如 `requestId`、`timestamp`、`traceId` 等动态噪声字段。
  - 级联忽略：忽略父级路径时自动排除其下所有子级变动。
  - 支持查看已忽略路径、单项恢复与全部恢复。
- **贴心的开发者交互**：
  - 支持格式化（单侧/双侧）、交换两侧、清空、一键加载模拟接口数据。
  - 单独提示哪一侧 JSON 存在语法错误，并尽量显示行列号与错误位置。
  - 1 MiB 单侧输入容量限制与清晰提醒。
  - 内容变更即时标记过期（Stale Banner），避免误读旧结果。
  - 差异列表支持按“新增 / 删除 / 值变化 / 类型变化”进行分类筛选。
  - 超长字段值支持折叠与展开，支持一键复制路径和单项值。
  - 差异过多时支持分页浏览（10/25/50/100 条每页），保证界面丝滑流畅。

## 🚀 安装与使用指南

### 在 Google Chrome 中安装（加载已解压的扩展程序）

1. **构建扩展产物**（若已构建直接跳至步骤 2）：
   ```bash
   npm run build
   ```
   构建完成后会在项目根目录下生成 `dist/` 目录。

2. **在 Chrome 浏览器中加载**：
   - 打开 Chrome 浏览器，在地址栏输入并回车：`chrome://extensions/`
   - 在页面右上角开启 **「开发者模式」 (Developer mode)** 开关。
   - 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)** 按钮。
   - 在弹出的文件选择器中，选择本项目的 **`dist` 目录**（即 `/Users/renyb/projects/josnCompare/dist`）。
   - 点击确认后，即可在扩展程序列表中看到 **JSON Compare - 接口差异对比工具**。

3. **使用方式**：
   - 点击浏览器右上角扩展拼图图标，将 JSON Compare 钉选在工具栏。
   - 点击该扩展图标，将自动在新标签页中打开独立的完整比对工作台。
   - 点击右上角「加载示例」可直接体验完整的业务变动排查与路径过滤流程。

## 🛠 本地开发与构建

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装依赖
```bash
npm install
```

### 本地开发调试
```bash
npm run dev
```

### 运行自动化单元测试
```bash
npm test
```
测试套件基于 Vitest，覆盖高精度数值、JSON Pointer 编解码、1 MiB 解析边界、嵌套增删改查、数组按序比较、父路径级联忽略等 22 项测试。

### 生产打包构建
```bash
npm run build
```
打包输出目录为 `dist/`，包含 `manifest.json` (Manifest V3)、`service-worker.js`、`index.html` 以及离线静态资源。

## 📐 比较规则与设计哲学

| 场景 | 行为说明 |
| :--- | :--- |
| **对象键顺序不同** | 判定为无差异（例如 `{"a": 1, "b": 2}` 与 `{"b": 2, "a": 1}` 相等）。 |
| **数值形态** | `1` 与 `1.0`、`100` 与 `1e2` 视为数值相等；数字 `1` 与字符串 `"1"` 判定为类型改变。 |
| **超长整数 ID** | 使用 `lossless-json` 无损解析和高精度十进制比较，避免 JavaScript 原生 Number 精度丢失。 |
| **空值与边界** | 缺失 (`missing`)、`null`、`""`、`0`、`false` 严格区分，不产生隐式类型转换混淆。 |
| **父级增删** | 对象/数组整体新增或删除时，仅记录一条父级记录，不向下递归重复统计成百上千条子属性。 |
| **数组比较** | 数组按顺序索引严格比对，第 $i$ 项与第 $i$ 项对比。超出部分按新增/删除处理。 |
| **忽略规则** | 使用 RFC 6901 JSON Pointer 规范定位。忽略某路径时，该路径及下属所有子节点在两侧均被排除。 |

## ⚠️ 已知限制（第一版范围说明）

1. **数组按 ID 智能对齐**：当前版本数组严格按索引位置对比，暂未引入按主键 ID（如 `id` 或 `skuId`）自动对齐的功能。
2. **全局通配符忽略**：忽略路径为用户指定的确切路径（如 `/data/order/timestamp` 或 `/trace`），本版不提供类似 `*.timestamp` 的全局正则忽略。
3. **无持久化存储**：为了保证绝密接口参数与业务数据的安全，本插件不使用本地磁盘或 Chrome Storage 暂存数据，刷新或关闭标签页后数据即自动销毁。
